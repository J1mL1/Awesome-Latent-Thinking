# Contributing

Contributions are welcome.

This list is curated, not exhaustive. Please suggest only resources that are clearly relevant to latent thinking, latent Chain-of-Thought, continuous reasoning, implicit reasoning, multimodal latent reasoning, or causal/mechanistic analysis of reasoning representations.

## Inclusion Criteria

A resource should satisfy at least two of the following:

- It directly proposes a latent, continuous, hidden-state, modality-grounded, or implicit reasoning method.
- It analyzes internal reasoning representations.
- It studies causal effects of intermediate reasoning states.
- It provides code, benchmark infrastructure, or evaluation protocols for latent reasoning.
- It is technically influential, well-documented, or clearly useful to researchers in this area.

## Pull Request Guidelines

Before opening a pull request:

- Check that the resource is not already listed.
- Verify the link points to a primary or official source.
- Use the existing table format.
- Add the entry to the most specific taxonomy section.
- Write a concise, neutral description.
- Do not add promotional language.
- Do not add unverifiable claims.

Preferred format:

```markdown
| Year | Title | Venue | Paper | Code/Data | Tags | Note |
| ---- | ----- | ----- | :---: | :-------: | ---- | ---- |
| 2026 | Example Paper | arXiv | [Paper](https://arxiv.org/abs/xxxx.xxxxx) | [Code](https://github.com/example/repo) | `method`, `hidden-state` | Introduces a latent reasoning process using hidden-state recurrence. |
```

## Not Accepted

The following are usually not accepted:

- Generic LLM prompting guides.
- Resources unrelated to latent or implicit reasoning.
- Broken links.
- Unofficial mirrors when an official source exists.
- Purely promotional pages.
- Low-quality or unmaintained repositories.
- Entries generated without source verification.
